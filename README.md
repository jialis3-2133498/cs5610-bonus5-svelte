# CS5610 Bonus Task 5 — Svelte Counter

## Overview

This project is a simple interactive counter application built with Svelte 5, JavaScript, and CSS for CS5610 Web Development.

## Features

- A 2×2 grid of interactive cells.
- Each cell toggles between white (off) and black (on) when clicked.
- A counter displays the number of active (black) cells.
- Parent-to-child communication using Svelte props and callback functions.

## How to Run

1. Clone the repository.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

4. Open the local URL displayed in the terminal.

## Technologies

- Svelte 5
- JavaScript
- CSS
- Vite
